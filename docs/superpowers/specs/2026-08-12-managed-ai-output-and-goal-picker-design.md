# 托管 AI 输出上限与拆解目标选择器设计

日期：2026-08-12
状态：已完成交互决策与自检，等待用户复审

## 目标

1. 为托管 DeepSeek 请求强制设置 `max_tokens: 2048`，控制异常长输出导致的成本上界。
2. 在 AI 工作台的“拆解目标”模式中，既支持自由输入，也支持从未完成任务中搜索并选择一个已有目标。

## 非目标

- 不改变免费终身 10 次、Pro 每日 20 次的额度规则。
- 不改变 BYOK 请求；用户自带 Key 时仍由所选服务商和模型配置决定输出参数。
- 不新增持久化“目标”实体，不修改 SwiftData schema。
- 不把选择器加入“今日计划”或“复盘”模式。
- 不自动修改、完成或归档被选中的原任务。

## Worker 成本护栏

`workers/quota-proxy/src/contract.js` 定义唯一常量 `MAX_COMPLETION_TOKENS = 2048`。`parseChatBody` 完成现有请求体、消息数量、角色和内容长度校验后，始终返回：

- 原请求中允许透传的字段；
- 强制模型 `deepseek-v4-flash`；
- 强制 `max_tokens: 2048`。

客户端未传 `max_tokens`、传入更大值、更小值、零、负数、字符串或 `null` 时，托管请求的上游值都固定为 `2048`，客户端不能绕过成本上限。这样输出长度和产品体验稳定，也避免不同客户端形成不同的托管额度价值。

Worker 不在响应返回后截断文本，因为截断发生得太晚，无法减少模型计费，并可能破坏 JSON 结果。

## 候选任务范围

目标选择器仅展示：

- `isArchived == false`；
- `isCompleted == false`；
- 标题去除首尾空白后非空。

候选项来自当前 `TodoViewModel` 中的未归档任务，因此包括自然语言“捕捉”创建的任务、手动创建任务和 AI 导入任务。

默认排序顺序：

1. 进行中任务优先于待办任务；
2. 优先级从高到低；
3. 有截止时间的任务优先，截止时间从近到远；
4. 更新时间从新到旧；
5. UUID 字符串作为稳定兜底顺序。

搜索匹配任务标题、上下文、验收标准、下一步提示和 `sourceGoal`，采用大小写不敏感、首尾空白忽略的包含匹配。

## 交互设计

AI 工作台切换到“拆解目标”时，在现有目标输入框上方显示“选择已有任务”入口。

点击后打开可搜索任务面板：

- 顶部是搜索框；
- 分为“进行中”和“待办”两组；
- 每行显示标题、任务类型、优先级和截止时间；
- 点击一行即选择并关闭面板；
- 面板提供“直接输入新目标”，用于清除当前任务选择但保留自由输入能力；
- 空结果提供明确提示，不影响自由输入。

选择任务后：

- 目标输入框填入该任务标题；
- 输入框继续可编辑；
- 输入框上方显示已选任务摘要，并提供“更换”和“清除”；
- 用户编辑目标文字时，仍保留所选任务的结构化上下文；
- 只有主动清除、改选任务、被选任务删除/完成/归档，或离开拆解模式时才清除关联；清除关联不清空已输入文字。

动态字体下任务行允许纵向展开；所有入口、搜索、任务行、清除和选择状态都有 VoiceOver 标签。动画遵守 Reduce Motion。

## 数据模型与数据流

新增轻量值类型 `AISelectedGoalContext`，仅存在于内存，包含：

- 任务 ID；
- 标题；
- 上下文；
- 验收标准；
- 下一步提示；
- 任务类型；
- 优先级；
- 预计分钟；
- 截止时间；
- 用上述字段生成的稳定 fingerprint。

`AIBriefingViewModel` 保存 `selectedGoalTaskID`。选择任务时写入 ID 和标题，并使旧工作台结果失效。执行拆解时根据最新 `TodoItem` 构造 `AISelectedGoalContext`；如果任务已不再符合候选条件，则清除关联、保留文本，并按自由输入执行。

`AIWorkbenchRequest` 与 `AIWorkbenchProvenance` 增加可选 `selectedGoalFingerprint`。这样任务的上下文、验收标准等在请求期间变化时，旧结果会被标为过期，不能导入。

`AIAssistantServing.workbench` 接收可选的 `selectedGoal`。远端提示词在拆解模式下增加一个结构化的“selected task”区块；本地规划器仍可使用目标文字完成兜底，不要求联网。其他模式不传选中任务详情。

## 隐私与日志

选中任务的结构化字段仅在用户触发“智能拆解”且通过现有远程 AI 同意流程后发送。现有同意文案已经覆盖任务标题、状态、优先级、截止时间和上下文；不新增日志，不记录提示词、响应、API Key 或任务正文。

## 错误与边界状态

- 无候选任务：显示空状态，用户继续自由输入。
- 任务在面板打开期间完成或删除：选择动作重新校验；无效任务不建立关联。
- 任务在请求期间变化：结果保留展示但标记为过期，禁止导入。
- 任务选择后目标文字为空：仍可用选中任务标题恢复并执行；若任务也失效，则按空输入阻止生成。
- Worker 收到客户端自定义模型或输出上限：模型和 `max_tokens` 都由 Worker 强制覆盖。
- DeepSeek 因输出达到上限返回不完整 JSON：沿用现有远端解析失败后本地规划器兜底行为。
